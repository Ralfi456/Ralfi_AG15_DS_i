. 📝 Descrição
Página web responsiva desenvolvida como portfólio acadêmico para apresentar meus projetos e trajetória na área de Desenvolvimento de Sistemas.

. 🛠️ Tecnologias
HTML5
CSS3
Bootstrap 5
Git e GitHub Pages

. ⚙️ Funcionamento
O site utiliza o conceito de página única com uma barra de navegação superior fixa. Através dos links, é possível navegar de forma fluida pelas seções de Perfil, Habilidades, Projetos e Contato.

.✨ Recurso Novo
Seção de Habilidades com Barras de Progresso:** Exibição visual do nível de conhecimento nas tecnologias estudadas.
Efeito Hover nos Cards:** Animação de elevação e sombra nos cartões de projetos ao passar o mouse.

. Implementação
HTML:** Adicionada uma nova seção utilizando classes do Bootstrap (`progress`, `progress-bar`, `card`).
CSS:** Aplicadas propriedades de transição (`transition: transform 0.3s ease`) e a pseudo-classe `:hover` para criar o efeito dinâmico nos elementos.
